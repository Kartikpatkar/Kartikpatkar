## 🚀 Featured Extensions

*Eleven published Chrome extensions. Zero external servers. 100% client-side.*

### [Apex Genie](https://github.com/Kartikpatkar/json-2-apex-genie)
**Convert JSON to strongly typed Apex classes locally.**
One-click JSON to Apex generation with automated test classes. Modular, themeable, and completely offline-first.
`JavaScript` `Apex` `Chrome Extension`
[Install Extension](https://chrome.google.com/webstore/detail/json-to-apex-genie/ifliljlnfdnmagdgmomglfoimjcnpinb)

### [SF Security Auditor](https://github.com/Kartikpatkar/sf-security-auditor)
**Audit Salesforce security directly from the browser.**
Analyzes profiles, permission sets, and object access without data leaving the org. Exports professionally formatted Excel workbooks.
`Metadata API` `ExcelJS` `Chrome Extension`
[Install Extension](https://chromewebstore.google.com/detail/mbanedjmimggapgpcnlhbndmdmehpolj)

### [SF Vault+](https://github.com/Kartikpatkar/sf-vault)
**Offline-first credential & org manager.**
Store, manage, and one-click login across Production, Sandbox, and Scratch orgs without relying on cloud password managers.
`Manifest V3` `Local Storage` `Chrome Extension`
[Install Extension](https://chromewebstore.google.com/detail/jpdnbaplnomajdlomcmbpfklcolgbljo)

### [FieldForge](https://github.com/Kartikpatkar/fieldforge)
**Bulk-create custom fields safely.**
Upload CSV/XLSX to define multiple custom fields, preview metadata, validate against the org, and deploy safely via the Metadata API.
`Metadata API` `Chrome Extension`
[Install Extension](https://chromewebstore.google.com/detail/nfjjccdcnpdmfglblfnkmmfecmblbhfo)
